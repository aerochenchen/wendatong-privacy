欢迎使用「问答通」（下称「本应用」或「我们」）。本应用由立人达创新工作室开发并运营，是装在 Windows 上的个人单机版资料问答工具：您把文件放进自建分类，用自然语言提问；回答依据已入库的正文，并标出出处。本政策适用于通过 Microsoft Store 安装的版本，以及在本机运行的同款个人桌面程序。

我们深知办公资料与个人信息的重要性。本政策说明我们如何处理与本应用相关的信息，以及您享有的权利。使用本应用即表示您已阅读并理解本政策；涉及需征得同意的处理活动，我们将在相关场景另行取得您的同意。

本政策同时参照《中华人民共和国个人信息保护法》《中华人民共和国数据安全法》《中华人民共和国网络安全法》等适用法律，以及 Microsoft Store 对隐私政策的要求编写。

如您不同意本政策，请停止使用本应用，并可卸载本应用、删除本机相关数据。

2. 我们如何理解「收集」与「处理」

  • 本机处理：资料原文、抽出的文字、检索数据、问答记录和模型配置保存在您的电脑本地，不上传至我们运营的服务器。本应用不设用户账号，也不设开发者自建的云端用户数据库。
  • 本机检索：入库后的向量检索在这台电脑上完成。检索所用模型随安装包提供，不因检索而把资料库发给开发者。
  • 离开本机：当您提问时，本应用会把当前问题、同一轮中为追问所需的近期问答，以及从已可提问资料中检索出的摘录，发送至您自行配置的模型服务（设置中的「模型服务地址」）。该服务由相应提供方运营，适用其自身的服务条款与隐私政策。
  • 我们（开发者）不上收：当前版本不包含将您的资料、提问、设备标识或使用行为发送至开发者自有分析、广告或崩溃统计服务器的功能。

就「数据是否离开设备、并可被开发者或第三方访问」而言，本应用需向您说明的主要离机内容是用户内容（问题与资料摘录）。接收方是您配置的模型服务，不是开发者。仅保存在本机的资料库与问答记录，不构成向开发者收集上报。

3. 我们处理哪些信息

3.1 为提供核心功能而在本机保存的信息

下列信息保存在您的设备上。Windows 上的默认目录为当前用户的 %LOCALAPPDATA%\wenda-tong（即 AppData\Local\wenda-tong）。您也可以用环境变量 WENDA_TONG_DATA 指定其他目录。这些内容不会由本应用主动上传至开发者服务器：

类型示例目的
资料文件您入库的原文、抽出的文字、检索数据在本机按分类保存，并供提问时检索
分类您自建的分类名称组织资料；出处使用「分类名 · 文件名」
问答记录时间、问题、回答、出处在本机回看历史或删除单条记录
模型服务配置服务地址、模型名称连接您指定的对话模型
模型 API 密钥您选填并保存在本机的密钥向模型服务鉴权
界面偏好文字大小记住您选择的显示设置

本应用不会为「备份到开发者云端」而复制您的资料全文。界面里不能打开或下载已入库的原文；要查看原文，请使用您自己保存的那份文件。

3.2 为完成问答而可能离开本机的信息

当您在问答中发送问题，且已配置可用的模型服务时，本应用可能将以下内容发送至该服务：

  • 当前问题；
  • 同一轮对话中、为继续追问而附带的近期问答；
  • 从已入库且状态为「可提问」的正文中检索出的摘录。

处理目的：由您配置的模型依据这些材料生成回答。资料里没有能支撑的内容时，回答会说明资料里没有这段记载。

法律基础：履行您使用本应用所必需的服务；当您把接口配置为会处理敏感内容，或该接口位于境外时，还基于您主动配置并使用该地址的同意。

图片可以入库，但当前版本不能识别图中文字，因此不会把图中的字当作摘录发送。音频和视频不会入库。

3.3 我们不会主动收集的信息

本应用不提供账号注册或登录，因此不收集注册用的姓名、手机号、电子邮箱、密码等。

当前版本亦不主动收集：广告标识符、精确地理位置、通讯录、相机或麦克风内容、支付银行卡信息，也不通过第三方分析或广告组件向开发者上报崩溃或用量统计。

若您通过 Microsoft Store 获取本应用，微软可能按其自身隐私声明处理商店账号、下载与更新记录。本应用不会因此获得您的微软账号密码或支付信息。本应用免费，不含应用内购买。

3.4 关于敏感个人信息

本应用不主动采集生物识别、行踪轨迹等敏感个人信息类别。但您入库或输入的规定、笔记、报表、说明中，可能包含身份证号、联系方式、未公开事项等敏感或内部信息。

请您仅在有权处理的材料上使用本应用，并审慎选择模型服务的部署位置（优先本机或单位内网）。一旦摘录发往模型服务，将受该服务方的处理规则约束。

4. 我们如何使用信息

我们仅在下列目的范围内处理上述信息：

  1. 提供与维护本应用功能（资料入库与分类、本机检索、问答、历史、模型设置、界面文字大小）；
  2. 在回答中标出出处，并在资料不能支撑时说明没有相应记载；
  3. 应您的请求提供支持（仅当您主动通过邮件向我们发送相关材料时，包括您报告生成内容不当或有害的情形）；
  4. 履行法律法规规定的义务。

我们不会将您的本机资料或提问用于向您展示个性化广告，不会出售您的个人信息，也不会用这些内容训练开发者自己的模型。回答由您配置的模型生成，开发者不运营该模型。

5. 委托处理、共享、转让与公开披露

5.1 模型服务提供方（第三方）

为实现问答，您需要自行配置兼容的模型服务地址、模型名称，以及在该服务要求时填写的密钥。向该地址发送的问题与资料摘录，由相应模型服务提供方处理。请在使用前阅读并同意该提供方的条款与隐私政策，并确认其部署位置（本机、境内内网、公网或境外）符合您所在单位与适用法律的要求。

我们不会在您不知情的情况下，将您的内容发送至我们另行指定的、与您配置无关的模型服务。

5.2 开发者

除您主动来信并提供的信息外，当前版本不向开发者服务器共享您的资料、提问、回答或本机应用数据。

5.3 转让与公开披露

我们不会出售您的个人信息。如因合并、分立、重组等需转移个人信息处理相关资产，我们将要求承继方继续受本政策约束，或重新征得您的同意（法律另有规定的除外）。

非经法律要求或获得您的同意，我们不会公开披露您的个人信息。

5.4 系统组件

当前版本不嵌入面向开发者收集数据的第三方分析、广告类组件。窗口只在本机使用，界面通过系统中的 Microsoft Edge WebView2 显示本机页面；本应用借此加载的是本机界面，不把资料库提交给微软做产品分析。程序只在本机回环地址 127.0.0.1:8091 提供界面与接口，不向局域网中的其他电脑开放。

6. 存储地点、期限与安全措施

6.1 存储地点

  • 本机数据：存储于您的 Windows 电脑本地磁盘（默认见第 3.1 节）。安装与升级不会把该目录上传到开发者的云端。
  • 模型服务侧：若发生离机传输，存储与保留规则由您配置的模型服务提供方决定，可能位于境内或境外机房。

6.2 保存期限

  • 资料、问答记录、模型配置与界面偏好：在您保留本机资料目录期间持续保存。
  • 您可以在「历史」中删除单条问答记录，在「资料」中删除文件或整个分类。删除后，相应内容不再参与回答。
  • 从 Microsoft Store 卸载本应用会移除程序本身。本机资料目录默认仍会保留；要彻底清除，请在卸载后自行删除该文件夹（若您设置了 WENDA_TONG_DATA，请删除您指定的那个目录）。
  • 发往模型服务的内容：以该服务方的保留政策为准。

6.3 安全措施

我们采取与个人单机使用相匹配的措施，包括：资料与记录留在本机、检索在本机完成、窗口不向局域网开放、模型只连接您保存的地址。任何措施都无法保证绝对安全。请妥善保管您的设备与 API 密钥，并避免在不可信网络环境下把敏感材料发往公网模型。

7. 跨境提供个人信息

本应用本身不运营用于汇聚用户资料的境外服务器。

是否构成向境外提供个人信息，取决于您配置的模型服务地址：

  • 若地址指向本机或境内单位内网模型，通常不因本应用而额外产生向境外提供；
  • 若地址指向境外或境外主体运营的公网模型服务，则您向该服务发送的问题与摘录可能构成跨境提供。此时，请您确认已满足适用的合法基础（如单独同意等），并遵守您所在单位及监管要求。

我们建议机关与企事业单位用户优先配置单位审批的内网或本机模型。

9. 未成年人保护

本应用面向个人查阅资料的场景，主要供成年人使用。我们不会故意收集未满十四周岁未成年人的个人信息。若您是未成年人的监护人，发现未成年人在未经同意的情况下向模型服务提交了个人信息，请联系我们。我们将协助指导您在本机删除相关数据，并配合依法处理。

10. 第三方产品与链接

本应用对接的是由您自行填写地址的模型服务。该服务有独立的隐私与安全实践，请您自行审慎评估。本政策仅约束「问答通」个人单机版本身的数据处理行为。

11. 本政策的变更

我们可能适时修订本政策。更新后，我们将通过应用内提示、产品页面或本页面公布的方式告知生效日期。若变更导致处理目的、方式发生重大变化，我们将依法重新征得同意（如适用）。

请您定期查阅本页面以获取最新版本。
